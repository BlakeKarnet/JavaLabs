# Java Labs

Учебный репозиторий для лабораторных работ по Java.

## Структура

```text
lab01/
  src/main/java/org/example/lab01/

lab02/
  src/main/java/org/example/lab02/

lab03/
  src/main/java/org/example/lab03/
```

## Как работать

1. Каждую лабораторную работу храни в отдельной папке `labNN`.
2. Java-классы размещай внутри `src/main/java`.
3. Пакеты называй в стиле `org.example.lab01`.
4. Для каждой новой лабораторной делай отдельный commit.

## Пример commit-сообщений

```text
Add lab01 solution
Fix lab02 input validation
Refactor lab03 classes
```
